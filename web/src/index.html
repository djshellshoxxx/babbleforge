About this demo

This page runs the same C++ masking engine as the BabbleForge desktop app, compiled to WebAssembly, with the same factory data files (areas, strategies, macros, spectrum targets). Settings map to a preset document that goes through the engine's own compose → validate → plan pipeline; plan changes use the engine's crossfades.

Privacy: everything runs locally in your browser. No audio, settings or analytics leave your device; the page only downloads its own files.

Level: meters show digital level (dBFS / LUFS) only — not SPL.

Differences from the desktop app: output goes to the browser's default stereo device (multichannel layouts are folded to stereo); the engine renders ~0.5 s ahead in a Web Worker, so setting changes are heard after about half a second; there is no device selection, preset library, corpus import, or real-time thread priority.
